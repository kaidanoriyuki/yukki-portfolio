# Yukki Portfolio（静的サイト Ver.2）

## 開き方
1. ZIPを解凍します。
2. VS Codeで `yukki_portfolio_rebuild_v2` フォルダを開きます。
3. `index.html` をブラウザで開きます。Live Server拡張機能を使ってもOKです。

## ファイルの役割
- `index.html`：ページの文章と7つのセクション
- `css/style.css`：色・配置・余白・スマートフォン対応
- `js/main.js`：スマホメニューと制作実績のタグ絞り込み
- `assets/`：参考画像から切り出したビジュアル素材（ユーザー提供のデザイン画像を使用）

## 7セクション
01 Header / 02 Hero / 03 About Me / 04 Skills / 05 Works / 06 Contact / 07 Footer

## まず変更する場所
- **色**：`css/style.css` 冒頭の `:root` の `--green` など
- **文章**：`index.html` 内の各セクション
- **スキル**：`index.html` の `skill-card` をコピーして追加
- **制作実績**：`work-card` をコピー。`data-tags="HTML CSS"` のように技術タグを空白区切りで指定
- **作品画像**：`assets/` 内の画像を入れ替えて `<img src="...">` を変更
- **メール**：`index.html` の `hello@example.com` を本物の連絡先に変更

## WordPress化について
この段階ではWordPressは未導入です。次の工程で `header.php`、`footer.php`、`front-page.php` などに分け、Skills/Worksを管理画面から登録できるようにします。現在のタグ色はCSSで一括指定しています。

## 注意
参考画像の一部を切り出した仮素材を使用しています。元画像は完成イメージなので、素材の切り出し部分には背景や文字が少し含まれる場合があります。公開時は独立した高解像度の素材に差し替えることをおすすめします。
作品詳細リンクは未設定です（存在しないURLへリンクしないようにしています）。お問い合わせメールは仮のアドレスです。
